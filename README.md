# Портфолио Ани Апполоновой

Статический сайт на HTML, CSS и JavaScript. Node.js нужен только для локального сервера; пакетов и сборки нет.

Репозиторий: https://github.com/anyapp-cpu/anyapp-cpu.github.io

## Публикация

Главный файл входа — `index.html` в корне репозитория. Перед каждой загрузкой проверять его наличие и доступность всех подключённых стилей, скриптов, изображений и шрифтов.

Для GitHub Pages использовать ветку `main`, каталог `/ (root)`. Файл `.nojekyll` позволяет раздавать сайт без обработки Jekyll.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:5173. Другой порт: `PORT=8080 npm run dev`.

## Файлы

- `index.html` — тексты, контакты и шесть кейсов с описанием вклада и результатов.
- `about.html`, `about.css`, `about.js` — страница «Обо мне», адаптивная вёрстка и навигация по разделам. Тексты основаны на CV в Buildin и уточнениях Ани о менторстве и увлечениях.
- `styles.css` — Onest, кейсы по одному в строке: обложка слева, тексты и кнопки справа, адаптация для телефона и планшета.
- `warp.js` — WebGL-искажение с локальной пикселизацией вслед за курсором. Квадраты размером 16 CSS px появляются при движении и затухают примерно в 2,3 раза медленнее warp-искажения. На сенсорных устройствах, при отключённых анимациях в системе или недоступном WebGL показывается оригинальное изображение.
- `assets/girl-laptop-plaza.png` — иллюстрация на первом экране.
- `assets/fonts/` — локальный Onest и лицензия OFL.

«Работы» в меню и футере ведёт к кейсам. «Обо мне» открывает отдельную страницу `about.html` с профилем, опытом, менторством, навыками, образованием и личным разделом. Боковая навигация ведёт к разделам и подсвечивает текущий при прокрутке. Обложки и кнопки опубликованных кейсов открывают подробные страницы в Buildin. Для ВТБ указано NDA и устный рассказ, для недвижимости — статус «скоро». Почта открывает почтовый клиент, Telegram и «Написать мне» открывают профиль Ани.

Обложки и подписи перенесены из старого портфолио: https://buildin.ai/share/2eadaa30-c796-4464-a477-4ca6c0cd0983?code=EZSG33. Файлы обложек находятся в `assets/cases/`: четыре анимированных и два статичных WebP. Пропорции исходников сохранены; анимации оптимизированы до 10 кадров в секунду. При `prefers-reduced-motion: reduce` показываются статичные версии. Все описания и результаты видны сразу; прогнозы помечены как ожидаемый эффект.

Для статического хостинга загрузить `index.html`, `about.html`, `styles.css`, `about.css`, `warp.js`, `about.js` и каталог `assets`. `server.mjs` и Node.js на хостинге не нужны.
