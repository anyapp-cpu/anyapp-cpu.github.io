# Портфолио Ани Апполоновой

Статический сайт на HTML, CSS и JavaScript. Node.js нужен только для локального сервера; пакетов и сборки нет.

Репозиторий: https://github.com/anyapp-cpu/anyapp-cpu.github.io

## Публикация

Главный файл входа — `index.html` в корне репозитория. Перед каждой загрузкой проверять его наличие и доступность всех подключённых стилей, скриптов, изображений и шрифтов.

Для GitHub Pages использовать ветку `main`, каталог `/ (root)`. Файл `.nojekyll` позволяет раздавать сайт без обработки Jekyll.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:5173. Другой порт: `PORT=8080 npm run dev`.

## Файлы

- `index.html` — тексты, контакты и шесть кейсов с описанием вклада и результатов.
- `works.html` — отдельная страница «Работы»: те же шесть кейсов с обложками и анимациями, без приветственного блока и плашки LegalTech.
- `about.html`, `about.css`, `about.js` — страница «Обо мне», адаптивная вёрстка и навигация по разделам. Тексты основаны на CV в Buildin и уточнениях Ани о менторстве и увлечениях.
- `gocomment.html`, `gocomment.css`, `gocomment.js` — внутренняя страница GoComment на основе интервью: контекст продукта, работа с правками, демо и первый проект, мобильные сценарии, локализация и результаты. Есть навигация по разделам, переключение коллекций переменных и увеличение макетов. Макеты экспортированы из предоставленной Figma в SVG и находятся в `assets/gocomment/vectors/`. В локальных копиях заменены имена, проекты, даты, номера, счётчики и обложки; исходные Figma-файлы не изменялись. Тексты внутри SVG переведены в контуры. Интерфейсы остаются векторными, фотографии интерьера и корпуса телефонов созданы для демонстрации. Оригинальный эмодзи руки встроен в SVG как PNG; пазл удалён из локальных макетов. Геометрия бейджей, счётчиков и строк пересчитывается по ширине текста скриптом `scripts/gocomment/prepare.py`. Редактор переменных реконструирован по реальным коллекциям и значениям UI Kit. Моковые данные экранов не являются бизнес-метриками продукта. Источники изображений перечислены в `assets/gocomment/sources.json`.
- `wildberries.html`, `wildberries.css`, `wildberries.js` — внутренний кейс WB Продвижение: исследования, 14 исходных цитат, матрица майндсетов, семь демонстраций и итог. Внешние края плашек и текстовые колонки используют общую сетку, цитаты занимают равные колонки; типографика опирается на GoComment. Оригиналы семи видео берутся из авторской папки `видео Wildberries/`. Скрипт `python3 scripts/wildberries/prepare_videos.py /absolute/path/to/ffmpeg` создаёт MP4 H.264 Baseline/avc1 с faststart (вместе около 13 МБ), резервные WebM VP9 (около 12 МБ) и постеры. В именах производных файлов есть хеш оригинала, чтобы браузер не использовал старые ответы. `assets/wildberries/video-manifest.json` связывает каждый ролик с разделом кейса, именем исходника и SHA-256. Ролики используют нативный автоплей без звука и по кругу с обычными элементами управления. Прокрутка не приостанавливает видео; после возврата браузера воспроизведение восстанавливается. Ручная пауза сохраняется. Сервер поддерживает MP4/WebM и диапазоны байтов для перемотки. Векторные визуалы взяты только со страницы «финальный прототип» (`1916:290032`) файла `86UJA435OsDTXzGFX8AKva`. В SVG калькулятора растр используется только для фотографий товаров. У панели прокрутки дней удалено внешнее серое поле экспорта. Источники перечислены в `assets/wildberries/sources.json`.
- `styles.css` — Onest, кейсы по одному в строке: обложка слева, тексты и кнопки справа, адаптация для телефона и планшета. Общий компонент `.section-navigation` задаёт единый вид навигации по разделам для «Обо мне», GoComment и Wildberries: нейтральная скруглённая плашка текущего раздела, общие отступы, типографика, наведение и фокус. На узком экране пункты переносятся в несколько строк.
- `warp.js` — WebGL-искажение с локальной пикселизацией вслед за курсором. Квадраты размером 16 CSS px появляются при движении и затухают примерно в 2,3 раза медленнее warp-искажения. На сенсорных устройствах, при отключённых анимациях в системе или недоступном WebGL показывается оригинальное изображение.
- `case-cover.js` — Lottie-обложки ВТБ, GoComment и недвижимости: локальный SVG-плеер lottie-web 5.13.0 и JSON загружаются за 300 px до появления обложки. Воспроизведение приостанавливается вне экрана и в скрытой вкладке. При отключённых анимациях в системе JSON и плеер не загружаются; при ошибке остаётся статичная обложка. Лицензия плеера находится в `assets/vendor/lottie-web-LICENSE.md`.
- `assets/girl-laptop-plaza.png` — иллюстрация на первом экране.
- `assets/fonts/` — локальный Onest и лицензии OFL на используемые шрифты.

«Работы» в меню и футере открывает отдельную страницу `works.html`. Ссылки «Все работы» внутри кейсов возвращают к соответствующей карточке на этой странице. «Обо мне» открывает отдельную страницу `about.html` с профилем, опытом, менторством, навыками, образованием и личным разделом. Боковая навигация ведёт к разделам и подсвечивает текущий при прокрутке. Обложки и кнопки GoComment и Wildberries открывают внутренние страницы `gocomment.html` и `wildberries.html`, остальные опубликованные кейсы открываются в Buildin. В конце GoComment есть переход к Wildberries, а в конце Wildberries — к Правительству Москвы, в соответствии с порядком карточек на Главной и в «Работах». Для ВТБ указано NDA и устный рассказ, для недвижимости — статус «скоро». Почта открывает почтовый клиент, Telegram и «Написать мне» открывают профиль Ани.

Обложки и подписи перенесены из старого портфолио: https://buildin.ai/share/2eadaa30-c796-4464-a477-4ca6c0cd0983?code=EZSG33. Файлы обложек находятся в `assets/cases/`. Для ВТБ используется предоставленная Lottie-анимация `vtb.json`: 1440 × 900, 60 кадров/с, цикл около 3 с, 232 КБ. Lottie-обложки используют один общий плеер; прежний `vtb.webp` сохранён, но главная страница его больше не загружает. Для GoComment используется предоставленная Lottie-анимация `gocomment.json`: 1440 × 900, 60 кадров/с, цикл 24,8 с. Плашка и метка комментария заменены встроенными векторными SVG; фотографии и аватары сохранены. JSON, плеер, загрузчик и статичная обложка вместе весят около 1,81 МБ против 2,86 МБ у прежнего WebP. Старый `gocomment.webp` сохранён, но главная страница его больше не загружает. Для Брички подключён предоставленный GIF `brichka.gif`: 1440 × 900, 45,92 МБ, без перекодирования; прежний WebP сохранён, но главная страница его не загружает. Для недвижимости используется предоставленная Lottie-анимация `real-estate.json`: 1440 × 900, 60 кадров/с, цикл 6,8 с, 3,56 МБ; прежний анимированный WebP сохранён, но главная страница его больше не загружает. Обложки Wildberries и Правительства Москвы — предоставленные статичные JPEG `wildberries.jpg` и `moscow.jpg`, 1920 × 1080, без перекодирования. Прежние WebP сохранены, но главная страница их не загружает. Пропорции исходников сохранены. При `prefers-reduced-motion: reduce` показываются статичные версии. Все описания и результаты видны сразу; прогнозы помечены как ожидаемый эффект.

Для статического хостинга загрузить `index.html`, `works.html`, `about.html`, `gocomment.html`, `wildberries.html`, `styles.css`, `about.css`, `gocomment.css`, `wildberries.css`, `warp.js`, `about.js`, `gocomment.js`, `wildberries.js`, `case-cover.js` и каталог `assets`. Оригиналы из `видео Wildberries/` и старого локального архива `sources/wildberries/originals/` загружать на хостинг не нужно. `server.mjs` и Node.js на хостинге не нужны. После обновления локального сервера перезапустить его: он должен поддерживать `.json` с типом `application/json` и `.mp4` с типом `video/mp4`, включая диапазоны байтов для перемотки.
