# Портфолио Ани Апполоновой

Статический сайт на HTML, CSS и JavaScript. Node.js нужен только для локального сервера; пакетов и сборки нет.

Репозиторий: https://github.com/anyapp-cpu/anyapp-cpu.github.io

## Публикация

Главный файл входа — `index.html` в корне репозитория. Перед каждой загрузкой проверять его наличие и доступность всех подключённых стилей, скриптов, изображений и шрифтов.

Для GitHub Pages использовать ветку `main`, каталог `/ (root)`. Файл `.nojekyll` позволяет раздавать сайт без обработки Jekyll.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:5173. Другой порт: `PORT=8080 npm run dev`.

## Файлы

- `index.html` — тексты, контакты и шесть заглушек кейсов.
- `styles.css` — Onest, сетка, адаптация для телефона и планшета.
- `warp.js` — WebGL-искажение с локальной пикселизацией вслед за курсором. Квадраты размером 16 CSS px появляются при движении и затухают примерно в 2,3 раза медленнее warp-искажения. На сенсорных устройствах, при отключённых анимациях в системе или недоступном WebGL показывается оригинальное изображение.
- `assets/girl-laptop-plaza.png` — иллюстрация на первом экране.
- `assets/fonts/` — локальный Onest и лицензия OFL.

«Работы» и «Обо мне» намеренно неактивны в меню и футере. Обложки кейсов пока не ведут на страницы. Почта открывает почтовый клиент, Telegram и «Связаться» открывают профиль Ани.

Для статического хостинга загрузить `index.html`, `styles.css`, `warp.js` и каталог `assets`. `server.mjs` и Node.js на хостинге не нужны.
