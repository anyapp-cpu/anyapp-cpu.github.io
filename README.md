# Портфолио Ани Апполоновой

Статический сайт на HTML, CSS и JavaScript. Node.js нужен только для локального сервера; пакетов и сборки нет.

Репозиторий: https://github.com/anyapp-cpu/anyapp-cpu.github.io

## Публикация

Главный файл входа — `index.html` в корне репозитория. Перед каждой загрузкой проверять его наличие и доступность всех подключённых стилей, скриптов, изображений и шрифтов.

Для GitHub Pages использовать ветку `main`, каталог `/ (root)`. Файл `.nojekyll` позволяет раздавать сайт без обработки Jekyll.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:5173. Другой порт: `PORT=8080 npm run dev`.

## Файлы

- `index.html` — тексты, контакты и шесть кейсов с описанием вклада и результатов.
- `works.html` — отдельная страница «Работы»: те же шесть кейсов с обложками и анимациями, без приветственного блока и плашки LegalTech.
- `about.html`, `about.css`, `about.js` — страница «Обо мне», адаптивная вёрстка и навигация по разделам. Тексты основаны на CV в Buildin и уточнениях Ани о менторстве и увлечениях.
- `gocomment.html`, `gocomment.css`, `gocomment.js` — внутренняя страница GoComment на основе интервью: контекст продукта, работа с правками, демо и первый проект, мобильные сценарии, локализация и результаты. Есть навигация по разделам, переключение коллекций переменных и увеличение макетов. Макеты экспортированы из предоставленной Figma в SVG и находятся в `assets/gocomment/vectors/`. В локальных копиях заменены имена, проекты, даты, номера, счётчики и обложки; исходные Figma-файлы не изменялись. Тексты внутри SVG переведены в контуры. Интерфейсы остаются векторными, фотографии интерьера и корпуса телефонов созданы для демонстрации. Оригинальный эмодзи руки встроен в SVG как PNG; пазл удалён из локальных макетов. Геометрия бейджей, счётчиков и строк пересчитывается по ширине текста скриптом `scripts/gocomment/prepare.py`. Редактор переменных реконструирован по реальным коллекциям и значениям UI Kit. Моковые данные экранов не являются бизнес-метриками продукта. Источники изображений перечислены в `assets/gocomment/sources.json`.
- `wildberries.html`, `wildberries.css`, `wildberries.js` — внутренний кейс WB Продвижение: исследования, 14 исходных цитат, матрица майндсетов, семь демонстраций и итог. Внешние края плашек и текстовые колонки используют общую сетку, цитаты занимают равные колонки; типографика опирается на GoComment. Оригиналы семи видео берутся из авторской папки `видео Wildberries/`. Скрипт `python3 scripts/wildberries/prepare_videos.py /absolute/path/to/ffmpeg` создаёт MP4 H.264 Baseline/avc1 с faststart (вместе около 13 МБ), резервные WebM VP9 (около 12 МБ) и постеры. В именах производных файлов есть хеш оригинала, чтобы браузер не использовал старые ответы. `assets/wildberries/video-manifest.json` связывает каждый ролик с разделом кейса, именем исходника и SHA-256. Ролики используют нативный автоплей без звука и по кругу с обычными элементами управления. Прокрутка не приостанавливает видео; после возврата браузера воспроизведение восстанавливается. Ручная пауза сохраняется. Сервер поддерживает MP4/WebM и диапазоны байтов для перемотки. Векторные визуалы взяты только со страницы «финальный прототип» (`1916:290032`) файла `86UJA435OsDTXzGFX8AKva`. В SVG калькулятора растр используется только для фотографий товаров. У панели прокрутки дней удалено внешнее серое поле экспорта. Источники перечислены в `assets/wildberries/sources.json`.
- `brichka.html`, `brichka.css`, `brichka.js` — внутренний кейс Брички: продукт и роль, заказ, интерактивные шаги торга, поездка, бонусы, предзаказ и работа с внутренними инструментами. Навигация и типографика общие с другими кейсами. 15 SVG экспортированы только с Page 13 (`1307:106162`) Figma-файла `tYH4GTz1BTmAXsFdiYHfJg`. Исходная растровая карта сохранена в положении и масштабе Figma, интерфейс и маршрут остаются векторными. Для телефонов используется сборка мокапа GoComment. Заполнение SVG подогнано к окну устройства без белых полос. Все парные блоки, фотографии и текстовые секции используют общие равные колонки и интервал 40 px. В локальных копиях согласован расчет оплаты. Скрипт `scripts/brichka/prepare.py` готовит SVG, `typography.py` обновляет типографику текста страницы. Источники и уточнения находятся в `assets/brichka/sources.json`. Водительские макеты и админка не опубликованы. Локальные оригиналы из папки «Бричка» исключены из Git.
- `styles.css` — Onest, кейсы по одному в строке: обложка слева, тексты и кнопки справа, адаптация для телефона и планшета. Общий компонент `.section-navigation` задаёт единый вид навигации по разделам для «Обо мне», GoComment и Wildberries: нейтральная скруглённая плашка текущего раздела, общие отступы, типографика, наведение и фокус. На узком экране пункты переносятся в несколько строк.
- `warp.js` — WebGL-искажение с локальной пикселизацией вслед за курсором. Квадраты размером 16 CSS px появляются при движении и затухают примерно в 2,3 раза медленнее warp-искажения. На сенсорных устройствах, при отключённых анимациях в системе или недоступном WebGL показывается оригинальное изображение.
- `case-cover.js` — Lottie-обложки ВТБ, GoComment и недвижимости: локальный SVG-плеер lottie-web 5.13.0 и JSON загружаются за 300 px до появления обложки. Воспроизведение приостанавливается вне экрана и в скрытой вкладке. При отключённых анимациях в системе JSON и плеер не загружаются; при ошибке остаётся статичная обложка. Лицензия плеера находится в `assets/vendor/lottie-web-LICENSE.md`.
- `assets/girl-laptop-plaza.png` — иллюстрация на первом экране.
- `assets/fonts/` — локальный Onest и лицензии OFL на используемые шрифты.

«Работы» в меню и футере открывает отдельную страницу `works.html`. Ссылки «Все работы» внутри кейсов возвращают к соответствующей карточке на этой странице. «Обо мне» открывает отдельную страницу `about.html` с профилем, опытом, менторством, навыками, образованием и личным разделом. Боковая навигация ведёт к разделам и подсвечивает текущий при прокрутке. Обложки и кнопки опубликованных кейсов открывают внутренние страницы `gocomment.html`, `wildberries.html`, `moscow.html` и `brichka.html`. Ссылки на кейсы в опыте на странице «Обо мне» ведут на те же страницы. Описания вклада и результатов согласованы с превью на Главной и в «Работах»; прогнозы для Wildberries и Правительства Москвы обозначены как ожидаемый эффект. В конце GoComment есть переход к Wildberries, а в конце Wildberries — к Правительству Москвы, в соответствии с порядком карточек на Главной и в «Работах». Для ВТБ указано NDA и устный рассказ, для недвижимости — статус «скоро». Почта открывает почтовый клиент, Telegram и «Написать мне» открывают профиль Ани. Рядом с «Написать мне» на странице «Обо мне» размещена кнопка «Скачать CV» с общим стилем `.case-link`. До добавления файла CV кнопка неактивна; при подключении файла нужно заменить её ссылкой с атрибутом `download`.

Обложки и подписи перенесены из старого портфолио: https://buildin.ai/share/2eadaa30-c796-4464-a477-4ca6c0cd0983?code=EZSG33. Файлы обложек находятся в `assets/cases/`. Для ВТБ используется предоставленная Lottie-анимация `vtb.json`: 1440 × 900, 60 кадров/с, цикл около 3 с, 232 КБ. Lottie-обложки используют один общий плеер; прежний `vtb.webp` сохранён, но главная страница его больше не загружает. Для GoComment используется предоставленная Lottie-анимация `gocomment.json`: 1440 × 900, 60 кадров/с, цикл 24,8 с. Плашка и метка комментария заменены встроенными векторными SVG; фотографии и аватары сохранены. JSON, плеер, загрузчик и статичная обложка вместе весят около 1,81 МБ против 2,86 МБ у прежнего WebP. Старый `gocomment.webp` сохранён, но главная страница его больше не загружает. Для недвижимости используется предоставленная Lottie-анимация `real-estate.json`: 1440 × 900, 60 кадров/с, цикл 6,8 с, 3,56 МБ; прежний анимированный WebP сохранён, но главная страница его больше не загружает. Обложки Wildberries и Правительства Москвы — предоставленные статичные JPEG `wildberries.jpg` и `moscow.jpg`, 1920 × 1080, без перекодирования. Прежние WebP сохранены, но главная страница их не загружает. Пропорции исходников сохранены. При `prefers-reduced-motion: reduce` показываются статичные версии. Для статического хостинга загрузить `index.html`, `works.html`, `about.html`, `gocomment.html`, `wildberries.html`, `styles.css`, `about.css`, `gocomment.css`, `wildberries.css`, `warp.js`, `about.js`, `gocomment.js`, `wildberries.js`, `case-cover.js` и каталог `assets`. Оригиналы из `видео Wildberries/` и старого локального архива `sources/wildberries/originals/` загружать на хостинг не нужно. `server.mjs` и Node.js на хостинге не нужны. После обновления локального сервера перезапустить его: он должен поддерживать `.json` с типом `application/json` и `.mp4` с типом `video/mp4`, включая диапазоны байтов для перемотки.


## Кейс Правительства Москвы

`moscow.html`, `moscow.css`, `moscow.js` оформляют внутреннюю страницу карьерной платформы. Обложка и «Смотреть кейс» на главной и в `works.html` ведут на неё. Типографика, общая сетка и навигация используют стили существующих кейсов. Страница включает четыре группы desk research, аудит текущего пути, 22 интервью, матрицу четырёх майндсетов, шесть инсайтов и восемь авторских цитат. Два фрагмента цитат сокращены до точных выдержек. Цель 50% → 70% относится к доходимости между отдельными этапами. Метрики запуска и подробности реализации не заявлены; юзабилити-тесты по просьбе автора не описываются.

Все 13 роликов подготовлены из `видео ПМ/`, включая новую запись `чат-бот.mov`. Соответствие разделам, размеры и SHA-256 источников находятся в `assets/moscow/video-manifest.json`. Записи экрана от 18:46:59 и 19:10:20 соответствуют атласу направлений и офлайн-заданию. Скрипт `python3 scripts/moscow/prepare_videos.py /absolute/path/to/ffmpeg` создаёт локальные MP4 H.264 Baseline/avc1 с faststart, резервные WebM и постеры; все выходные видео полностью декодируются для проверки. MP4 вместе весят около 59 МБ. Ролики автоматически воспроизводятся без звука и повторяются; доступны ручная пауза и увеличение. Запись Telegram вписана в смартфон, выполненный на CSS, с сохранением пропорций видео. Веб-версии записи чат-бота обрезаны до 14 секунд перед появлением рамки записи экрана; исходник сохранён.

Векторные экраны экспортированы со страницы «Макеты» `3142:1092` файла Figma `TTLpOezm9U0AjrL2h2A3ID`. Растр в SVG используется только для исходного портрета. Для обеих диаграмм восстановлены потерянные экспортёром цвета десяти сегментов из read-only Plugin API, для открытой матрицы также восстановлен исходный blur 12 px средствами SVG. Данные для воспроизведения находятся в `assets/moscow/chart-source.json` и `assets/moscow/dashboard-chart-source.json`; для каждого файла используется скрипт `python3 scripts/moscow/repair_chart.py <path-to-source-json>`. Figma-файл не изменялся. Источники и редакторские уточнения перечислены в `assets/moscow/sources.json`.

При публикации добавить `moscow.html`, `moscow.css`, `moscow.js` и `assets/moscow/`. Папку оригиналов `видео ПМ/` загружать не нужно; она исключена из Git.

Редакторские правки: инсайты сгруппированы по майндсетам; в каждой карточке сначала идут подзаголовок и пояснение, затем цитаты. В мокапе используется Dynamic Island и единая обрезка видео по скруглениям. После изменения текстов запускать `python3 scripts/moscow/typography.py`: скрипт расставляет неразрывные дефисы и пробелы после предлогов, включая составные, только в видимом тексте и текстовых атрибутах; ссылки, пути и идентификаторы сохраняются.
